# Leave-Management-App


A full-stack web application designed to streamline the employee leave request process. The platform supports a clear, multi-stage approval workflow with distinct roles for Employees, Managers, and HR personnel.

## ✨ Features

* **Role-Based Workflows:** Distinct login portals and dashboards for Employee, Manager, and HR.
* **Multi-stage Approval:** Seamless approval pipeline (Employee → Manager → HR).
* **Smart Conflict Detection:** Automatically warns managers if multiple teammates request leave on the same dates.
* **Auto-Escalation:** Leave requests sitting too long in a manager's queue are automatically escalated to HR.
* **Instant Registration:** New users can register and instantly access the employee dashboard.
* **Responsive UI:** Clean, intuitive interface built with React.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, CSS
* **Backend:** Java 17, Spring Boot 3
* **Database:** H2 (Embedded File Database)
* **Deployment:** Docker (Multi-stage build), Render
